# Quill for Windows

Quill is a free AI email assistant. Paste an email, say what you want to answer, and Quill writes the reply in your own voice — with your real prices, policies and sign-off. You copy it and send it yourself; Quill never sends anything on its own.

This is the Windows program: Quill in a small 6 × 9 inch box that sits beside your inbox, with a talk-or-type bar at the bottom. Resize it to any size or go full screen.

**Website:** https://quill-email-ai.lovable.app

## Download

Get **Quill-windows-x64.zip** from the [latest release](https://github.com/ehelferich/quill-windows/releases/latest), or straight from the website's download section.

## Install (about 1 minute)

1. Unzip the file you downloaded (about 115 MB).
2. Open the `Quill-win32-x64` folder and double-click **Quill.exe**.
3. If Windows shows "Windows protected your PC", click **More info → Run anyway**. This appears because the early version isn't code-signed yet.
4. Sign in with the same account you use on the website, phone or browser extension. Everything you've taught Quill is already there.

## Handy shortcuts

| Shortcut | What it does |
| --- | --- |
| Ctrl + 0 | Snap back to the compact 6 × 9 inch box |
| Ctrl + 1 | Teach Quill |
| Ctrl + 2 | Write an Email |
| Ctrl + , | Settings |

## Requirements

Windows 10 or 11 (64-bit) and an internet connection.

## Privacy

Quill only reads an email when you paste or share it. See the [Privacy Policy](https://quill-email-ai.lovable.app/privacy) and [Terms of Service](https://quill-email-ai.lovable.app/terms).
